  `LIMITI.md` (fin dove si può spingere il gioco), le richieste scritte a Codex (`RICHIESTA_PER_CODEX.md`, `RICHIESTA_PER_CODEX_3.md`; la 2 è in `archivio/`, superata).
- `../materiale_chat/` · i testi di Codex da cui si genera `chat_dati.js` (comando in `RIGENERA.md`).
- `../strumenti/` · gli strumenti per le auto, la prova nel browser e il suono.
- `../test/` · i test (`node --test test/*.test.js`).
- Alla radice restano i file del gioco (HTML e JavaScript caricati da `index.html`), `README.md`, `AGENTS.md` e `PASSAGGIO.md`.
